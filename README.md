# Database Course – Repository Structure

This repository contains all homework assignments for the database course.

## 📌 Repository Structure

Each homework assignment is stored in its **own separate branch**.  
The `main` branch does not contain assignment files — it serves only as an entry point and documentation.

### 🔀 Branch Organization

Each branch includes:
- Logical schema (PDF/PNG/JPEG)
- SQL script (.sql)
- Additional documentation if required

## 📚 How to Access an Assignment

To view any homework:
1. Go to the repository.
2. Open the **branch selector**.
3. Choose the branch corresponding to the needed homework.

## ✔ Purpose of `main` Branch

The `main` branch acts as:
- a clean overview of the project structure  
- a navigation point for all assignments  
- a place for general documentation
